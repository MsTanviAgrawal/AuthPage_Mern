# AuthPage_Mern

AuthPage_Mern is a full-stack authentication application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The project provides a secure user authentication system with features such as user registration, login, password encryption, and JWT-based authentication.

The application demonstrates how to implement modern authentication workflows in a MERN environment while maintaining a clean and responsive user interface. It serves as a practical example for learning full-stack development, API integration, user session management, and secure authentication practices.

## Features
- User Registration and Login
- Secure Password Hashing using bcrypt
- JWT Authentication and Authorization
- Protected Routes
- MongoDB Database Integration
- RESTful API with Express.js
- Responsive React Frontend
- User Session Management

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcrypt
